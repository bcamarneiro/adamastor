# Standardize focus ring colors across all form inputs

## Overview

Form inputs across the application use inconsistent focus ring colors - some use blue-500, others use accent-9 or accent-7. This creates visual inconsistency and a disjointed user experience.

## Rationale

Consistent visual language across the application helps users build mental models and reduces cognitive load. Focus indicators are especially important for accessibility and should be predictable throughout the application.
