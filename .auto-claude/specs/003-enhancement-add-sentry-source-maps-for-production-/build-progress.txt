## Troubleshooting

### Source maps not uploading
- Verify SENTRY_AUTH_TOKEN is set and marked as Sensitive
- Check token has scopes: `project:releases`, `org:read`
- Confirm SENTRY_ORG and SENTRY_PROJECT match your Sentry dashboard URL

### Stack traces still minified
- Wait a few minutes for Sentry to process the release
- Verify release version matches (check Git commit SHA in Sentry)
- Ensure you're looking at errors that occurred AFTER the deployment

### Build failures
- Plugin only runs when NODE_ENV=production
- If auth token is missing, plugin will warn but not fail the build
