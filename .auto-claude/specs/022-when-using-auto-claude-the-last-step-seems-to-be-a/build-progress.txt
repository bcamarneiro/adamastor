   - Tool: retry_pr_creation
   - Description: "Retry a failed PR creation operation..."
   - Parameters: None (uses spec_dir from closure)
   - Features:
     * Validates status is "pr_creation_failed"
     * Checks can_retry and retry_count before retrying
     * Max 3 retry attempts (PR_MAX_RETRY_ATTEMPTS)
     * Exponential backoff: 2s, 4s, 8s (PR_INITIAL_BACKOFF_SECONDS * 2^retry_count)
     * Preserves error history for debugging
     * Clears pr_error on success
     * Provides retry hints in failure messages

8. Error clearing on success:
   - When PR creation succeeds, any previous pr_error is deleted
   - Code: `if "pr_error" in plan: del plan["pr_error"]`

Implementation Details:

Exponential Backoff Formula:
  backoff_seconds = PR_INITIAL_BACKOFF_SECONDS * (2 ** retry_count)
  - Attempt 1: 2 seconds wait (after retry_count=0)
  - Attempt 2: 4 seconds wait (after retry_count=1)
  - Attempt 3: 8 seconds wait (after retry_count=2)

Retry Flow:
1. Check status is "pr_creation_failed"
2. Check can_retry is True
3. Check retry_count < PR_MAX_RETRY_ATTEMPTS
4. Update status to "creating_pr"
5. Apply backoff delay
6. Attempt PR creation
7. On success: Set status to "human_review", clear pr_error
8. On failure: Update pr_error with new error info, increment retry_count

Error Type Classification:
- Retryable: network, timeout, rate_limit, server_error, unknown
- Not retryable: auth, exists, base_branch, not_found, gh_not_found

```python
def _guard_human_review_transition(plan, worktree_path=None, validate_pr=True):
    # Check pr_created exists
    pr_created = plan.get("pr_created")
    if not pr_created:
        return (False, "pr_created is not set")

    # Check pr_created is a dict
    if not isinstance(pr_created, dict):
        return (False, "pr_created is invalid type")

    # Check url exists
    pr_url = pr_created.get("url")
    if not pr_url:
        return (False, "pr_created.url is not set")

    # Check url is valid string
    if not isinstance(pr_url, str) or not pr_url.strip():
        return (False, "pr_created.url is invalid")

    # Optional: Validate PR exists via gh pr view
    if validate_pr and worktree_path:
        _validate_pr_exists(worktree_path, pr_url)  # Soft validation

    # All checks passed
    plan["status"] = "human_review"
    plan["planStatus"] = "review"
    return (True, f"Transitioning to human_review. PR #...")
```
