## 🗣️ Ponto Livre (Versão Casual + Técnica)

```
Pessoal, preciso de uma ajuda! 🙏

Estou a desenvolver o Adamastor, uma plataforma open-source para tornar o Parlamento português mais transparente. Basicamente, rastreia deputados, mede assiduidade, compara desempenhos, etc - tudo com dados objetivos.

🧪 Fase de Testes

Estou a recrutar testadores (não precisa saber programar!) para:
• Encontrar bugs 🐛
• Reportar confusões de UX
• Testar em mobile/tablet
• Sugerir melhorias

A ideia é simples: usas a plataforma naturalmente e reportas o que não faz sentido ou não funciona.

📖 Guia de Testing (em PT)
https://github.com/bcamarneiro/adamastor/blob/staging/TESTING.md

💬 Onde Reportar
https://github.com/bcamarneiro/adamastor/discussions

Criei categorias específicas por página (Ranking, Batalha Real, Distritos, etc) para facilitar a organização.

📊 Stack Técnica (para os curiosos)
- Next.js + TypeScript
- Supabase (PostgreSQL)
- Radix UI
- E2E tests com Playwright
- Monorepo com Turborepo

🎯 Principais Funcionalidades a Testar
1. **Ranking de Deputados** - Lista ordenável com notas
2. **Batalha Real** - Comparações 1v1 (deputados, distritos, partidos)
3. **Perfis de Deputados** - Métricas individuais, gráficos
4. **Calculadora de Desperdício** - Calcula custo de ausências
5. **Iniciativas Legislativas** - Lista de propostas

📱 Testa em:
- Desktop (Chrome, Firefox, Safari)
- Mobile (iOS, Android)
- Tablet

Se encontrares algo, mesmo que não tenhas a certeza se é bug, reporta na mesma! É melhor ter falsos positivos que deixar bugs por encontrar.

Quem conseguir, agradecia muito! Cada bug encontrado torna a democracia portuguesa mais transparente. 🇵🇹

PS: Projeto é totalmente open-source e sem fins lucrativos. O objetivo é mesmo transparência cívica.
```

## 🎯 Estratégia de Divulgação

### Fase 1: Círculo Próximo (Semana 1)
- Amigos que se interessam por política/tech
- Colegas de trabalho
- Comunidade local de programadores
- **Target:** 5-10 testadores

### Fase 2: Comunidades Online (Semana 2)
- Ponto Livre (tech community)
- Grupos de LinkedIn de civic tech
- Twitter tech PT
- **Target:** 20-30 testadores

### Fase 3: Media/Influencers (Se houver tração)
- Contactar jornalistas tech
- YouTubers de política PT
- Podcasts de democracia/tecnologia
- **Target:** Viralizar

### Timing Ideal
- **Melhor dia:** Terça ou Quarta-feira
- **Melhor hora:** 10h-12h ou 19h-21h
- **Evitar:** Fins de semana, feriados
